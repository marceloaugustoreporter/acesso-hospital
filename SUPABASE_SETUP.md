# Acesso+ Hospital v2.4 — ativar o painel coletivo ao vivo

O aplicativo funciona normalmente sem banco compartilhado. Para a apresentação, o Supabase permite que os celulares da turma enviem categorias anônimas de uso e que o painel mostre os números em tempo quase real.

## 1. Criar o projeto

1. Entre em https://supabase.com e crie uma conta/projeto gratuito.
2. Dê um nome como `acesso-hospital-puc`.
3. Guarde a senha do banco em local seguro. Ela NÃO entra no aplicativo.

## 2. Criar a tabela

No Supabase, abra **SQL Editor**, crie uma nova query e execute:

```sql
create table if not exists public.acesso_events (
  id bigint generated by default as identity primary key,
  created_at timestamptz not null default now(),
  session_code text not null,
  event_type text not null,
  profile text,
  resource text,
  location text,
  priority text,
  rating smallint check (rating between 1 and 5),
  outcome text
);

alter table public.acesso_events enable row level security;

create policy "demo_insert"
on public.acesso_events
for insert
to anon
with check (char_length(session_code) between 4 and 40);

create policy "demo_select"
on public.acesso_events
for select
to anon
using (char_length(session_code) between 4 and 40);
```

Se o editor informar que as policies já existem, não execute o bloco de criação de policies novamente.

## 3. Pegar os dois dados públicos

No projeto, abra **Project Settings > API** (ou a área de API/Connect, conforme a interface atual) e copie:

- **Project URL**
- **anon / public key**

Não use `service_role` e não coloque senha de banco no GitHub.

## 4. Configurar o app

Abra `config.js` e altere:

```js
window.ACESSO_LIVE = {
  enabled: true,
  supabaseUrl: 'SUA_PROJECT_URL',
  supabaseAnonKey: 'SUA_CHAVE_ANON_PUBLIC',
  defaultSessionCode: 'PUCMG-06102026',
  defaultSessionLabel: 'Apresentação PUC Minas — 06/10/2026'
};
```

Salve e envie os arquivos ao GitHub Pages.

## 5. Testar sem contaminar a apresentação

Para ensaio, abra:

`https://marceloaugustoreporter.github.io/acesso-hospital/?sessao=TESTE`

Todos os celulares que usarem `?sessao=TESTE` alimentarão apenas a sessão TESTE.

Na apresentação, use o endereço normal ou:

`https://marceloaugustoreporter.github.io/acesso-hospital/?sessao=PUCMG-06102026`

## 6. O que vai para o banco

Somente categorias necessárias ao painel:

- sessão;
- tipo de interação;
- perfil escolhido;
- recurso solicitado;
- setor/local escolhido;
- prioridade;
- nota de 1 a 5;
- resposta Sim/Parcialmente/Não.

O app NÃO envia ao painel compartilhado texto livre, nome, telefone, diagnóstico, observação clínica ou coordenadas GPS.
